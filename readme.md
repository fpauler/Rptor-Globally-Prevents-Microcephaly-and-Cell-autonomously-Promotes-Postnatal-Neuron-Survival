# Rptor/mTORC1 Function Globally Prevents Cortical Microcephaly and Cell-autonomously Promotes Postnatal Neuron Survival in a Cell Type Specific Manner

Raw figures/tables as well as scripts and other relevant information for analyses of RNA-Seq/Proteomics data in Villalba, Beattie, Pauler et al. Nature Communications 2026

------------------------------------------------------------------------

## General folder structure

### bulk_RNASeq

- this folder contains analyses for bulk RNA-Seq data

### scRNA-Seq

- this folder contains analyses for single cell RNA-Seq data 

------------------------------------------------------------------------

## More detailed description of folder content

### biorvix

this folder contains data relevant for the [bioRvix version of the manuscript](https://www.biorxiv.org/content/10.64898/2026.05.01.722172v1.abstract "bioRvix manuscript")

### final

this folder contains data/plots/scripts relevant for the latest version of the manuscript.

The folder plots contains data for Main figures (folder Main), Supplementary figures (folder Supplement), Quality Control (folder QC) and Reviewer's figures used to reply to reviewer's comments (folder reviewer).
